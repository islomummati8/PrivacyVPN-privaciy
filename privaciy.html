ENGLISH VERSION

1. Introduction

This Privacy Policy and Terms of Service govern all applications, services, and software provided by PrivacyVPN ("Service", "We", "Us"). Our goal is to provide secure, encrypted, and private internet access across Android, Windows desktop, and Web browser extensions (Chrome, Firefox, Edge, Opera).

2. Information Collection & Usage

We strictly practice data minimization to protect user anonymity:

a) Account Authentication (Firebase Auth)

  • Email & Password: Processed in encrypted format solely for user authentication.
  • Google Sign-In: Collects basic public profile identity (Email and Name) for account management.
  • Anonymous Sign-In: Generates a temporary unique token without storing personal details.

b) Operational Data

To ensure system stability, server balance, and service delivery, our servers temporarily process non-identifiable technical metrics:

  • Client application version and OS platform type (Android / Windows / Web Extension).
  • Aggregated data volume usage (in Megabytes) solely for bandwidth quota calculations.

3. Data We Never Collect (No-Logs Policy)

Our VLESS+Reality protocol architecture strictly prohibits logging the following:

  • Your real IP address or assigned server IP.
  • Visited websites, URLs, downloaded files, or session durations.
  • DNS queries or routed traffic contents.

4. System Permissions

a) Android Application

Requires VpnService API permission. This permission is strictly utilized to create an encrypted local tunnel for routing network traffic to VLESS VPN nodes.

b) Web Extensions (Chrome / Firefox / Edge)

Utilizes proxy and storage API permissions to manage proxy routing settings and persist connection preferences directly within the browser environment.

5. Acceptable Use & Terms of Service

Users agree not to utilize PrivacyVPN for illegal activities, including but not limited to cyberattacks, malware distribution, copyright infringement, or unauthorized system exploitation.
